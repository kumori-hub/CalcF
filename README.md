CalcF - Calculadora de Posologias

Como funciona

  O usuário deve selecionar qual tipo de fórmula farmacêutica quer calcular.
  Ao selecionar qual fórmula deve inserir os dados para os calculos e clicar em "Calcular Resultado" para ver quantos Cps/Frascos atendem por 1 e 2 meses de tratamento.
